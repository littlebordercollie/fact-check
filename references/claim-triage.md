# Claim 分类与分流

L1 离线层第二步的详细规则：怎么从一段文字里挑出该核查的句子，并判断哪些要联网。

核心目标：**不是每句都查，而是把该查的那一小撮筛出来。** 乱查既慢又烧，还净查些不用查的。

---

## 第一刀：是不是 claim？

只有“**可证伪的客观断言**”才进入核查。一句话能不能被证明是错的？

| 句子 | 是 claim 吗 | 理由 |
|---|---|---|
| “Transformer 在 2017 年提出” | ✅ 是 | 有客观对错 |
| “OpenAI 估值 3000 亿美元” | ✅ 是 | 可查证 |
| “我觉得这个工具很好用” | ❌ 不是 | 主观，不可证伪 |
| “这玩意快得飞起” | ❌ 不是 | 修辞夸张 |
| “很多人都在用 AI 写作” | ❌ 不是 | 口语化模糊量词，不必较真 |

主观判断、修辞、模糊量词——**直接放过**，别标。

---

## 第二刀：要不要联网？

挑出 claim 后，给每个打一个标签。判断标准就两个维度：**会不会过期** + **我有没有把握**。

### 🌐 必须联网

- **时效性强**：含“最新 / 现在 / 今年 / 上周 / 刚发布 / 目前”等，或涉及还在变化的数字（估值、排名、价格、版本号、人事任命）。
  - AI 训练数据有截止日期，这类是它最容易错、又最不自知的地方——**联网核查最大的价值区就在这里。**
- **具体可查但我没把握**：一个确切的数字/日期/归属，我无法凭训练知识确认。

### 💭 离线就能判

- **稳定常识**：物理常数、确立已久的历史事实、基础定义（“水沸点 100℃”“图灵测试由图灵 1950 年提出”）。模型训练数据里钉死的，有把握就直接判，不必浪费一次联网。
- 判断口诀：**这事五年前对、五年后还对吗？** 是 → 多半能离线判。

### ⏭️ 跳过

- 主观、修辞、模糊量词（第一刀已滤掉的那些）。

---

## 第三刀：重不重要？

就算是个可查的事实错误，也要看它**在不在论证的承重墙上**。

- 核心论点依赖它 → 标。
- 顺带提一句、错了也不影响主旨 → 可标可不标，倾向轻标一笔（“这个细节顺便核下”）。

> 记住容忍度：这是作者发布前自检，不是给论文挑刺。把火力集中在“错了会让读者被误导”的地方。

---

## 一个完整的分流示例

> 原文：“DeepSeek 上个月刚发布的新模型，参数量 6710 亿，性能据说追平了 GPT-4。我觉得这是国产模型的里程碑。”

拆解：

1. “上个月刚发布” → 🌐 时效性，联网确认发布时间
2. “参数量 6710 亿” → 🌐 具体数字，联网核实
3. “性能追平 GPT-4” → 🌐 可证伪但要注意：“据说”是模糊转述，联网时标注“原文已用‘据说’弱化，核查基准是哪个 benchmark”
4. “我觉得这是国产模型的里程碑” → ⏭️ 主观观点，跳过

→ 三条进 L2 联网，一条放过。这就是分流的样子。
